Cách đọc đề — theo đúng thứ tự nên làm

  1. "Luôn luôn / không bao giờ" = cơ chế tất định. Chọn hook, permission, limit, gate ngoài model; loại phương án sửa wording.
  2. Phòng ngừa thắng phát hiện. Đề nói "trước khi", "never", "contain" → loại log, audit hàng tuần, review sau, rotate.
  3. Mỗi cơ chế giải một việc. Caching = chi phí, window = sức chứa, temperature = ngẫu nhiên, batch = giá, streaming = perceived latency.
  4. Lỗi ở tầng nào? Input, index, retrieval, prompt, model, context hay giao hàng — đáp án đúng sửa đúng tầng.
  5. Đo trước, đổi sau. Đọc stop_reason, phân loại mẫu lỗi, baseline, eval set, A/B đồng thời; loại "launch rồi đo".
  6. Mẫu đơn giản nhất đủ dùng. Một call → chaining → routing → orchestrator-workers → agent; mỗi bậc phải có lý do trong đề.
  7. Đòn rẻ trước. Effort trước tier, rút output trước đổi model, batch cho tải không gấp; đổi model là phương án cuối.
  8. Đọc ràng buộc thật của workload. Không ai chờ thì latency không quan trọng → batch, tier mạnh hơn.
  9. Temperature và "nâng tier mạnh nhất" hầu như luôn sai. Không sửa trust model, vòng lặp, context thiếu, jailbreak hay format.
  10. Bảo model "bỏ qua" không gỡ token. Loại phương án dùng lời dặn thay cho cấu hình nạp context.
  11. "Select two" là hai mặt bổ trợ. Gate + sandbox, inline + fail closed, sampling + error-triggered, chuẩn hóa + validate, báo cáo + feedback.
  12. Câu stakeholder. Chọn minh bạch, kịp thời, đo được, có baseline, khuyến nghị kèm trade-off, ghi thành tài liệu; loại giấu điểm yếu, hứa tuyệt đối.

Viết tắt & thuật ngữ

Tra nhanh viết tắt và thuật ngữ, gộp từ 3 quiz.

Kiến trúc, agent & tool (14 mục)
MCP — Model Context Protocol. Chuẩn mở nối app AI với hệ thống ngoài.
A2A — Agent-to-Agent. Agent tự chủ của các tổ chức phối hợp.
SDK — Software Development Kit. Thư viện chính thức, có retry backoff.
Augmented LLM — Một call kèm retrieval, tool, memory.
Prompt chaining — Chuỗi bước cố định, output nối tiếp.
Routing — Phân loại input, gửi tới nhánh riêng.
Sectioning / voting — Hai biến thể của parallelization.
Orchestrator-workers — Phân rã động, giao worker, tổng hợp.
Evaluator-optimizer — Vòng viết – chấm – sửa.
Subagent — Agent con với context riêng, trả tóm tắt.
Tool search — Nạp tool definition khi cần.
Server tool — Tool chạy ở Anthropic: web search, code execution.
Capability bloat — Quá nhiều tool trùng lặp, không dùng.
MDM — Mobile Device Management. Phân phối cấu hình xuống máy.
Prompt, context & model (10 mục)
CoT — Chain-of-Thought. Suy luận từng bước trước kết luận.
TTS — Text-to-Speech. Engine đọc văn bản thành giọng nói.
TTFT — Time To First Token. Độ trễ tới token đầu tiên.
TTL — Time To Live. Thời gian cache entry tồn tại.
Breakpoint — Cache breakpoint. Điểm đánh dấu cuối prefix được cache.
Effort — Mức thinking, tool call, tự kiểm.
Context rot — Context càng dài, độ chính xác càng giảm.
Compaction — Server tóm tắt lượt hội thoại cũ.
Context editing — Server xóa tool result cũ khỏi context.
Progressive discovery / disclosure — Chỉ nạp metadata, nội dung khi cần.
RAG & truy xuất (7 mục)
RAG — Retrieval-Augmented Generation. Truy xuất tài liệu rồi sinh câu trả lời.
BM25 — Best Matching 25. Xếp hạng theo từ khóa (lexical).
Embedding — Vector biểu diễn nghĩa của đoạn văn.
Reranker — Model chấm lại độ liên quan ứng viên.
Chunk overlap — Chunk kề nhau chia sẻ phần lề.
Small-to-big — Parent document retrieval. Khớp chunk nhỏ, trả section cha.
OCR — Optical Character Recognition. Nhận dạng chữ từ ảnh scan.
Bảo mật & tuân thủ (14 mục)
WIF — Workload Identity Federation. Đổi identity workload lấy token ngắn hạn.
App Attest — Xác thực app iOS/macOS thật, cấp token.
Indirect prompt injection — Chỉ dẫn độc trong nội dung bên thứ ba.
Fail closed / fail open — Lỗi thì chặn / lỗi thì cho qua.
Circuit breaker — Ngắt khi vượt ngưỡng tổng.
HITL — Human-in-the-loop. Người duyệt trong luồng quyết định.
ZDR — Zero Data Retention. Không lưu dữ liệu, xét theo từng tính năng.
GDPR — General Data Protection Regulation. Luật dữ liệu EU, có quyền xóa.
PHI — Protected Health Information. Thông tin sức khỏe được bảo vệ.
HIPAA — Health Insurance Portability and Accountability Act. Luật Mỹ bảo vệ dữ liệu y tế.
FedRAMP — Federal Risk and Authorization Management Program. Cấp phép cloud cho cơ quan liên bang Mỹ.
TLS — Transport Layer Security. Mã hóa đường truyền.
Data lineage — Truy dấu nơi dữ liệu cá nhân đi tới.
Proxy variable — Trường gián tiếp mang tín hiệu nhân khẩu.
Đánh giá, vận hành & dự án (11 mục)
SLA — Service-Level Agreement. Cam kết mức dịch vụ có chỉ tiêu đo được.
p95 / p99 — 95th / 99th percentile. Độ trễ của 5% / 1% chậm nhất.
F1 — F1 score. Trung bình điều hòa precision, recall.
LLM-as-judge — Model chấm theo rubric, hiệu chuẩn với người.
A/B test — Hai biến thể chạy đồng thời, chia ngẫu nhiên.
Guardrail metric — Metric không được xấu đi khi thử nghiệm.
Data leakage — Test set trùng dữ liệu model đã thấy.
OTEL — OpenTelemetry. Chuẩn xuất metric, log, trace.
Correlation ID — Mã nối mọi bước của một request.
ADR — Architecture Decision Record. Ghi quyết định, phương án, trade-off.
Runbook — Hướng dẫn vận hành hệ thống đã xây.
