Lưu trữ khối — EBS

Cách đọc đề — theo đúng thứ tự nên làm

  1. Đọc câu hỏi cuối cùng trước, rồi mới đọc tình huống. Biết trước đề hỏi chi phí, hiệu năng hay công vận hành sẽ đọc đoạn mô tả nhanh hơn nhiều và không bị dẫn dắt bởi chi tiết thừa.
  2. Khoanh tròn từ định lượng: MOST, LEAST, cost-effective, operational overhead. Thường có nhiều đáp án chạy được về mặt kỹ thuật, chỉ một cái thỏa đúng tính từ đó — đây là nguồn mất điểm lớn nhất.
  3. "Least operational overhead" gần như luôn dẫn tới managed hoặc serverless. Thấy đáp án nào bắt tự cài, tự vá, tự scale máy chủ thì loại trước. Bậc thang chung: tự quản trên EC2 → RDS/ECS → Aurora/Fargate → Serverless/App Runner/Lambda.
  4. Loại trừ bằng một điều kiện cứng. Thường chỉ cần một chi tiết là gạch được 2–3 đáp án: chạy quá 15 phút thì Lambda ra, không được gián đoạn thì Spot ra, cần SMB thì EFS ra, cần thứ tự thì SQS Standard ra.
  5. "Select TWO/THREE" phần lớn là các bước bổ trợ của CÙNG một giải pháp, không phải lựa chọn độc lập. Ví dụ: endpoint phải đi kèm route, SCP phải đi kèm tag policy, user pool phải đi kèm identity pool, copy AMI phải đi kèm launch instance. Nếu 2 đáp án bạn chọn làm cùng một việc thì gần như chắc chắn sai một cái — nhưng cũng có đề dùng "Select TWO" cho hai giải pháp độc lập cùng thỏa một bài toán (ví dụ VPC peering HOẶC PrivateLink), nên luôn đọc kỹ ngữ cảnh.
  6. Cảnh giác đáp án đúng nhưng thừa. Đề hỏi least privilege mà đáp án cấp FullAccess, hoặc hỏi giải pháp vài ngày mà đáp án đòi viết lại kiến trúc — đúng kỹ thuật nhưng sai yêu cầu. "Không rearchitect" / "minimal configuration effort" là ràng buộc cứng, không phải gợi ý.
  7. Đề đã cho sẵn thứ gì thì thứ đó thường là một phần đáp án. Tình huống nói "đã có S3 event notification gửi vào SQS" thì đáp án xoay quanh SQS, không phải thay bằng Kinesis. Ngược lại, câu chữ tưởng như thừa ("dữ liệu đã nhân bản sang instance khác", "hạ tầng DR không cần hoạt động") thường chính là chìa khóa tháo gỡ ràng buộc.
  8. Chú ý giới từ chỉ thời điểm. "Mã hóa BEFORE upload" khác hẳn "mã hóa AT REST" — một chữ đổi cả đáp án.
  9. Với câu chính sách IAM/JSON dài: đọc Condition trước Action. Không khớp điều kiện thì cả statement coi như không tồn tại; Deny luôn thắng Allow khi cả hai cùng khớp. Đừng dịch xuôi từ trên xuống — tự hỏi "muốn Allow xảy ra cần đúng điều kiện gì" trước, rồi kiểm tra có Deny nào cắt ngang không.
  10. Phân biệt CloudTrail và AWS Config theo đúng chiều. CloudTrail trả lời "ai gọi API gì, khi nào, từ IP nào"; Config trả lời "resource đang cấu hình ra sao, có đổi so với trước không". Nhầm chiều là sai ngay lập tức.
  11. Khi đề có DR: định vị RTO/RPO cụ thể trước khi chọn chiến lược. Số càng nhỏ (RPO tính bằng giây/phút, RTO dưới 1 giờ) thì càng gần active-active/warm standby; số lớn (giờ/ngày) mới cân nhắc backup & restore hay pilot light.
  12. Khi đề liệt kê nhiều ràng buộc, tìm ràng buộc hiếm/khó thỏa nhất trước. Thường chỉ đúng một tổ hợp dịch vụ thỏa hết mọi điều kiện — tìm điều kiện hiếm sẽ loại được gần hết đáp án nhiễu ngay lập tức.
  13. Đừng chọn đáp án chỉ vì nó nghe hiện đại/hoành tráng hơn. Kinesis không phải lúc nào cũng hơn SQS; Lambda không phải lúc nào cũng hơn EC2; AMI + Auto Scaling group nhiều khi thắng cả việc viết lại thành container. Bám đúng ràng buộc đề nêu, không phải trực giác "cái nào nghe pro hơn".

Viết tắt & thuật ngữ

Phần phụ lục — tra nhanh khi gặp một chữ viết tắt lạ trong đề. Gộp từ danh sách gốc dùng chung cho toàn bộ 6 quiz.

Điện toán & container (12 mục)
EC2 — Elastic Compute Cloud. Máy chủ ảo, đơn vị điện toán cơ bản nhất.
AMI — Amazon Machine Image. "Bản chụp" một máy EC2 để tạo lại nhiều bản giống hệt.
ASG — Auto Scaling Group. Nhóm EC2 tự thêm/bớt máy theo tải.
ECS — Elastic Container Service. Dịch vụ chạy container riêng của AWS.
EKS — Elastic Kubernetes Service. Kubernetes được AWS quản lý.
CNI — Container Network Interface. Plugin mạng cho Kubernetes.
IRSA — IAM Roles for Service Accounts. Gắn IAM role riêng theo service account trong EKS.
HPC — High Performance Computing. Tính toán hiệu năng cao.
EFA — Elastic Fabric Adapter. Card mạng ảo tốc độ cực cao cho HPC/ML.
SaaS — Software as a Service. Phần mềm dùng ngay dưới dạng dịch vụ.
MGN — Application Migration Service. Di trú máy chủ kiểu lift-and-shift.
VM — Virtual Machine. Máy ảo.
Lưu trữ (15 mục)
S3 — Simple Storage Service. Kho lưu trữ object.
EBS — Elastic Block Store. Ổ đĩa ảo gắn vào một EC2.
EFS — Elastic File System. Hệ thống file dùng chung, nhiều EC2 mount cùng lúc.
FSx — (tên thương hiệu). Họ dịch vụ hệ thống file quản lý: Windows File Server, Lustre, ONTAP.
NFS — Network File System. Giao thức chia sẻ file chuẩn Linux/Unix.
SMB — Server Message Block. Giao thức chia sẻ file của Windows.
DFS/DFSR — Distributed File System (Replication). Cơ chế nhân bản file share của Windows Server.
NAS — Network Attached Storage. Thiết bị lưu trữ file chia sẻ qua mạng, thường on-premises.
IOPS — Input/Output Operations Per Second. Thước đo hiệu năng ổ đĩa.
VTL — Virtual Tape Library. Storage Gateway giả lập băng từ vật lý.
POSIX — Portable OS Interface. Chuẩn giao diện Unix mà EFS tuân theo.
DLM — Data Lifecycle Manager. Tự động tạo/xóa EBS snapshot theo lịch.
WORM — Write Once, Read Many. Đặc tính của S3 Object Lock.
HDD/SSD — Ổ cứng cơ / thể rắn. Quyết định loại EBS.
HDFS — Hadoop Distributed File System. Hệ thống file phân tán của Hadoop.
Mạng (16 mục)
VPC — Virtual Private Cloud. Mạng riêng ảo.
AZ — Availability Zone. Một trung tâm dữ liệu vật lý riêng biệt.
NAT — Network Address Translation. Cho subnet riêng tư ra internet mà không lộ IP thật.
CIDR — Classless Inter-Domain Routing. Cách viết dải IP, vd. 10.0.0.0/16.
ENI — Elastic Network Interface. Card mạng ảo gắn vào EC2.
NACL — Network Access Control List. Tường lửa cấp subnet, stateless.
SG — Security Group. Tường lửa cấp instance, stateful.
ALB/NLB/GWLB — Application/Network/Gateway Load Balancer. Layer 7 / Layer 4 / Layer 3.
VPN — Virtual Private Network. Đường hầm mã hóa qua internet công cộng.
DX — Direct Connect. Đường truyền vật lý riêng nối on-premises với AWS.
VIF — Virtual Interface. Giao diện ảo trên một kết nối Direct Connect.
BGP — Border Gateway Protocol. Giao thức định tuyến dùng với DX/VPN.
CDN — Content Delivery Network. Mạng phân phối nội dung nhiều điểm gần người dùng.
SSL/TLS — Secure Sockets Layer / Transport Layer Security. Giao thức mã hóa đường truyền.
WAF — Web Application Firewall. Tường lửa lọc traffic web theo luật.
VGW — Virtual Private Gateway. Cổng VPN phía AWS.
Bảo mật & danh tính (13 mục)
IAM — Identity and Access Management. Hệ thống quản lý user, role, quyền hạn.
KMS — Key Management Service. Dịch vụ quản lý khóa mã hóa.
SSE — Server-Side Encryption. Mã hóa phía server, tự động khi ghi vào S3.
CSE — Client-Side Encryption. Mã hóa ngay tại máy khách trước khi gửi đi.
AD — Active Directory. Dịch vụ thư mục xác thực của Microsoft.
STS — Security Token Service. Cấp credential AWS tạm thời.
OIDC — OpenID Connect. Giao thức xác thực dựa trên OAuth 2.0.
SCP — Service Control Policy. Chính sách giới hạn quyền tối đa cho AWS Organization.
OU — Organizational Unit. Đơn vị tổ chức trong AWS Organizations.
OCSF — Open Cybersecurity Schema Framework. Chuẩn dữ liệu bảo mật mà Security Lake dùng.
OCSP — Online Certificate Status Protocol. Kiểm tra chứng chỉ SSL còn hiệu lực.
RBAC — Role-Based Access Control. Phân quyền theo vai trò, dùng nhiều trong Kubernetes.
CN — Common Name. Trường tên miền trong chứng chỉ SSL.
Cơ sở dữ liệu, serverless & xử lý dữ liệu (16 mục)
RDS — Relational Database Service. Database quan hệ được quản lý.
DMS — Database Migration Service. Di trú database, downtime tối thiểu.
SCT — Schema Conversion Tool. Đi kèm DMS khi đổi engine.
DAX — DynamoDB Accelerator. Cache trong bộ nhớ đặt trước DynamoDB.
PITR — Point-In-Time Recovery. Khôi phục database về một thời điểm bất kỳ.
SQS — Simple Queue Service. Hàng đợi message.
SNS — Simple Notification Service. Dịch vụ pub/sub.
FIFO — First In, First Out. Loại hàng đợi giữ đúng thứ tự.
DLQ — Dead-Letter Queue. Hàng đợi hứng message lỗi.
MSK — Managed Streaming for Kafka. Apache Kafka được AWS quản lý.
KCL — Kinesis Client Library. Thư viện đọc dữ liệu từ Kinesis Data Streams.
ETL — Extract, Transform, Load. Quy trình mà AWS Glue thực hiện.
EMR — Elastic MapReduce. Dịch vụ Hadoop/Spark được quản lý.
CRON — (chronos). Định dạng lịch chạy dùng trong EventBridge Scheduler.
RAID — Redundant Array of Independent Disks. Ghép nhiều ổ đĩa để tăng tốc/độ bền.
BLOB — Binary Large Object. Dữ liệu nhị phân lớn lưu trong một cột database.
Vận hành, chi phí & khác (13 mục)
RAM (AWS) — Resource Access Manager. Chia sẻ subnet/Transit Gateway giữa account — khác nghĩa bộ nhớ.
GiB/TiB — Gibibyte/Tebibyte. Đơn vị nhị phân (2³⁰, 2⁴⁰) AWS hay dùng cho ổ đĩa, khác GB/TB thập phân.
TTL — Time To Live. Thời gian bản ghi còn hiệu lực (cache DNS, tự xóa item DynamoDB).
IA — Infrequent Access. Tầng lưu trữ S3 cho dữ liệu ít truy cập.
CRR — Cross-Region Replication. Nhân bản dữ liệu S3 sang Region khác.
DR — Disaster Recovery. Khôi phục sau thảm họa.
RTO — Recovery Time Objective. Thời gian tối đa chấp nhận để khôi phục.
RPO — Recovery Point Objective. Lượng dữ liệu tối đa chấp nhận mất.
HA — High Availability. Tính sẵn sàng cao.
IMDS — Instance Metadata Service. Dịch vụ nội bộ cho EC2 tự truy vấn thông tin.
PHI/PII — Protected Health / Personally Identifiable Information. Dữ liệu nhạy cảm Macie phát hiện.
SAA — Solutions Architect Associate. Chứng chỉ AWS mà bộ quiz này ôn luyện.
MPI — Message Passing Interface. Giao thức giao tiếp giữa node trong HPC tightly-coupled.
